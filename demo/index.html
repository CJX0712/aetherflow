AetherFlow

一个通用、可持久化、可观测的 AI Agent 运行时。 统一十余家模型供应商的协议差异，把工具失败变成模型自我修正的回路， 用事件溯源让崩溃可恢复，用录制重放让回归测试零成本且确定性。

$ npm install aetherflow

设计取舍

我们做对了几件别人容易做错的事。

↺

工具失败是反馈，不是异常

工具不存在、参数不合法、执行报错，都会作为 tool_result 回喂模型，触发自我修正，而不是让整个 Agent 崩溃。

⧉

结构化并发

TaskGroup 保证作用域退出时子任务必然结束或被取消。用 Promise.all 会留下继续烧钱的孤儿任务。

◇

不拆散工具调用与结果

上下文压缩时保证 tool_call 与其 tool_result 成对保留，否则供应商会直接拒绝请求 —— 长对话崩溃的常见根因。

⏱

崩溃可恢复

每个事件落盘、结果物化快照。进程重启后可从事件流重建现场，而不是让用户重跑一遍再付一次钱。

⊘

不信任模型输出

数学表达式用自研递归下降解析器求值，文件工具强制根目录校验。来自模型的输入被视为不可信输入。

◫

录制一次，重放千次

把真实调用固化为资产，回归测试无需联网、无需付费、结果确定 —— 这是 Agent 能进 CI 的前提。

代码

类型安全贯穿始终：工具入参由 zod 推导，结构化输出直接得到已校验的对象。
